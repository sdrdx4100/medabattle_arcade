# Medabattle Arcade Prototype

このリポジトリはArcadeライブラリを用いたメダロット風ATBシミュレーションRPGのプロトタイプです。
既存の3vs3シャトルラン式ATBをベースに、各機体の部位ごとに行動を選ぶ
「メダロットライク」なコマンド戦闘へ拡張しています。

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## 実行方法

```bash
python main.py
```

## 操作方法

* 方向キー: 選択/移動
* Enter/Space: 決定
* Esc: キャンセル/終了
* Tab/M: メニュー開閉

## シャトルランバトル

`python main.py` を実行するとタイトルメニューが表示され、
セーブスロットを選んで簡易ストーリーを読み進めると
3vs3 のシャトルラン式ATBバトルが開始されます。
ATBゲージが満タンになった味方にはコマンドメニューが表示され、
方向キーで部位コマンドを選び Enter/Space で決定します。

### バトルの特徴

* **最大3vs3のATB戦闘**: 味方3機・敵3機がリアルタイムでATBゲージを溜めます。
* **部位ベースのコマンド選択**: HEAD / 右うで / 左うで / 脚部ごとに
  別の攻撃を選択できます。
* **部位破壊システム**: 行動は対応する敵部位を狙い、壊した部位のコマンドは使用不能になります。
* **ターゲット選択**: 各コマンドの後に、3体の敵から狙う相手を選べます。
* **チームパネル表示**: 画面上部に味方・敵それぞれの部位HPが表示されます。

### コマンド例

* **ミサイル**: HEAD を狙う高命中射撃
* **ライフル**: 右うでパーツを狙う射撃
* **ハンマー**: 左うでパーツを狙う近接
* **レッグブレイク**: 脚部を狙う破壊行動
* **たいき**: そのターンの行動を見送ります

頭部が破壊された機体、または全部位が壊れた機体は機能停止します。
攻撃結果や勝敗は画面下部のメッセージウィンドウに表示されます。
どちらかのチームが全滅するとバトル終了です。

このプロジェクトは学習目的の簡易実装です。
